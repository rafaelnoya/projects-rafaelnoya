Algorithm Project 1: Space Invaders – Algorithmic Defense in Java

A console game inspired by Space Invaders with a matrix-based battlefield, where the player uses combat modules based on sorting algorithms (Selection Sort, Insertion Sort, Bubble Sort, Merge Sort, Quick Sort, and Heap Sort) to reorganize and eliminate invaders. It features custom implementations of all algorithms, performance statistics collection, the use of recursion, and a final comparative ranking, all without relying on built-in sorting libraries.
