Data Structures 1 Project: Klondike Solitaire in Java

Implementation of the classic Solitaire card game, where board and rule management is handled entirely through dynamic data structures built from scratch. The project uses custom implementations of Stacks (for the stock, waste, and foundation piles) and Lists (for the tableau columns), requiring the manual development of structural Nodes and Iterators to manipulate and move cards, without relying on the language's native collection libraries.
